# CAT Study Desk & 24-Skill Workbook (2021–2025)

An interactive CAT preparation desk covering all **15 actual CAT slots from 2021 to 2025 (1,002 questions across VARC, DILR, and QA)**, calibrated with difficulty tiers, target solve times, original exam diagram scans, and a 24-Skill Formula & Trap Workbench.

## Features
- **6-Day Study Plan**: Curated daily sessions (16–18 high-yield questions per day) designed for the final week before CAT without visual overwhelm.
- **24 Core CAT Skills & Formula Cheat Sheets**: Every question across 2021–2025 is mapped to one of 24 practical skills (11 QA, 6 DILR, 7 VARC) with key formulas, first-pass triggers, common CAT traps, and a personal confidence tracker (`Needs Practice` · `Getting There` · `Confident`).
- **Practice Desk with Original Exam Scans**: Pixel-cropped WebP slices from all 247 exam pages render alongside interactive MCQ options (with `Strike` elimination), TITA numeric keypad, a hideable timer, starting hints, and step-by-step verified solutions.
- **Past Papers & 40-Minute Section Timer**: Load any of the 15 actual slots (`2021`–`2025`, `Slot 1`–`3`) to practice 3-minute First-Pass (Round 1) selection and compare against official difficulty calibration.

## Running Locally

Serve the `public/` directory with any static HTTP server:

```bash
python3 -m http.server 8765 --directory public
```

Then open [http://localhost:8765](http://localhost:8765).
